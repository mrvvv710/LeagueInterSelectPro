1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей сайта Inter Select Pro (далее — «Сайт»), разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Оператором персональных данных является организация Inter Select Pro (далее — «Оператор»).

2. Какие данные мы собираем

При регистрации личного кабинета и использовании Сайта Оператор может собирать следующие данные:

  • Имя и фамилия
  • Адрес электронной почты
  • Пароль (хранится в зашифрованном виде)
  • Выбранный вид спорта
  • Статистика участия в матчах и турнирах
  • Фотографии и видеоматериалы, загруженные пользователем в медиатеку

3. Цели обработки данных

  • Создание и администрирование личного кабинета пользователя
  • Организация участия в турнирах и мероприятиях лиги
  • Отображение статистики, достижений и медиаматериалов пользователя
  • Связь с пользователем по вопросам, связанным с деятельностью лиги

4. Правовые основания обработки

Обработка персональных данных осуществляется на основании согласия субъекта персональных данных, предоставляемого при регистрации на Сайте.

5. Хранение данных

Персональные данные пользователей хранятся с использованием облачной инфраструктуры Supabase (базы данных PostgreSQL) с применением технических мер защиты, включая шифрование паролей.

6. Передача данных третьим лицам

Оператор не передаёт персональные данные пользователей третьим лицам, за исключением случаев, предусмотренных законодательством Российской Федерации, либо для обеспечения технической работы Сайта (хостинг-провайдеры, поставщики облачных сервисов).

7. Права субъекта персональных данных

Пользователь имеет право:

  • Получить информацию, касающуюся обработки его персональных данных
  • Требовать уточнения, блокирования или уничтожения своих персональных данных
  • Отозвать согласие на обработку персональных данных
  • Обратиться с жалобой в уполномоченный орган по защите прав субъектов персональных данных

8. Файлы cookie

Сайт может использовать технологию хранения данных в браузере (localStorage) для сохранения языковых настроек, темы оформления и сессии авторизации пользователя.

9. Изменения политики

Оператор оставляет за собой право вносить изменения в настоящую Политику. Актуальная версия всегда доступна на данной странице.

1. General Provisions

This Privacy Policy (the "Policy") defines how personal data of Inter Select Pro website users (the "Site") is processed and protected, in accordance with Federal Law No. 152-FZ "On Personal Data" of July 27, 2006.

The data controller is the Inter Select Pro organization (the "Operator").

2. What Data We Collect

When registering an account and using the Site, the Operator may collect the following data:

  • First and last name
  • Email address
  • Password (stored in encrypted form)
  • Selected sport
  • Match and tournament participation statistics
  • Photos and videos uploaded by the user to the media library

3. Purposes of Data Processing

  • Creating and administering the user's personal account
  • Organizing participation in league tournaments and events
  • Displaying user statistics, achievements, and media
  • Communicating with the user regarding league activities

4. Legal Basis for Processing

Personal data is processed on the basis of the consent of the data subject provided during registration on the Site.

5. Data Storage

User personal data is stored using Supabase cloud infrastructure (PostgreSQL databases) with technical protection measures applied, including password encryption.

6. Data Transfer to Third Parties

The Operator does not transfer users' personal data to third parties, except as required by Russian Federation law, or to ensure the technical operation of the Site (hosting providers, cloud service providers).

7. Data Subject Rights

The user has the right to:

  • Receive information regarding the processing of their personal data
  • Request correction, blocking, or deletion of their personal data
  • Withdraw consent to the processing of personal data
  • File a complaint with the authorized body for the protection of personal data subjects' rights

8. Cookies

The Site may use browser storage technology (localStorage) to save language settings, theme preferences, and user authorization sessions.

9. Policy Changes

The Operator reserves the right to make changes to this Policy. The current version is always available on this page.

10. Contact

For any questions related to the processing of personal data, please contact: info@interselectpro.ru
